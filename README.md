# E-commerce Shopper Intention

Proyecto de predicción de intención de compra en e-commerce usando el dataset [Online Shoppers Purchasing Intention](https://github.com/sharmaroshan/Online-Shoppers-Purchasing-Intention).

## Dataset

El archivo `data/online_shoppers_intention.csv` proviene del repositorio original de sharmaroshan/Online-Shoppers-Purchasing-Intention.

## Requisitos

- Python 3
- pandas
- scikit-learn
- Jupyter Notebook

python -m venv venv
